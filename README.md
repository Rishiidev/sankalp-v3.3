# Hanuman Sadhana

A private, discipline-focused spiritual practice PWA.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Checks

- Type-check: `npm run lint`
- Unit checks: `npm test`
- Production build: `npm run build`
